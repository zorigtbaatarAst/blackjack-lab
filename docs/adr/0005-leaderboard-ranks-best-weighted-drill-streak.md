# The leaderboard ranks the Best streak in the Weighted drill

Usion requires a leaderboard for every game. We rank on Best streak: the longest run of consecutive Book-matching Decisions in the Weighted drill. That rewards the skill the Lab teaches, not luck.

Only the Weighted drill counts. Play Decisions don't count, because real Rounds are mostly trivial Hard totals. The Mistakes drill doesn't count either, because it repeats cells the player has already been shown, which would make streaks easy to farm. Guests have no rank.

## Considered Options

- **Peak Bankroll:** rejected because it measures variance, and free Refills make it gameable.
- **Lifetime accuracy %:** rejected because it barely moves once a player is good.
